# EC7 Bearing Capacity Review Skill for Claude

This is a Claude Skill designed to support the review of shallow foundation bearing capacity checks in accordance with Eurocode 7.

The aim is not to replace engineering judgement or produce black-box design outputs.

The aim is to help engineers review calculations more consistently by checking whether key assumptions are stated clearly and whether the calculation logic is traceable.

## What the skill reviews

- Design Approach 1 Combination 1 and Combination 2
- Partial factors on actions and material parameters
- Effective foundation dimensions due to eccentricity
- Shape factors
- Inclination factors
- Groundwater assumptions
- Drained versus undrained parameter selection
- Traceability of governing combinations

## What it does not do

- It does not replace a competent geotechnical designer or checker
- It does not certify compliance
- It does not remove the need for project-specific judgement
- It does not validate the ground model or parameter derivation
- It should not be used without independent engineering review

## Intended use

This skill is intended as a technical review assistant for engineers who want to make bearing capacity calculations easier to interrogate, reproduce and defend.
